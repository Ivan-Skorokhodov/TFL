### Здача 1

Условие:
- Язык SRS $ac \to ca, c \to bcb, bc \to cb$ над базисом $a^nca^nc$

Заметим, что:
- во всем слове у нас четное количество $a$
- количество $c$ ровно 2 шт и оно не изменяется
- $c$ могут находится в любых позициях
- в каждом блоке с $b$ у нас четное количество $b$
- разные блоки из $b$ (где в каждом четное количество) могут разделяться только блоками из $a$ (считаем, что $c$ внутри блока $b$ никак его не разбивает его на 2 отдельных блока)

Согласно второй лабораторной работе 2 построим ПКА, который покажет что наш язык регулярный.
![ПКА](AFA.svg)

```
digraph AFA {
  rankdir=LR;
  node [shape = doublecircle]; 0; 2; 6;
  node [shape = circle];

  start [shape = point];
  start -> "&";
  
  "&" -> 0 [label = "E"];
  0 -> 1 [label = "b"];
  1 -> 0 [label = "b"];
  0 -> 0 [label = "а,c"];
  1 -> 1 [label = "c"];
  
  "&" -> 2 [label = "E"];
  2 -> 3 [label = "a"];
  3 -> 2 [label = "a"];
  2 -> 2 [label = "b,c"];
  3 -> 3 [label = "b,c"];
   
  "&" -> 4 [label = "E"];
  4 -> 5 [label = "c"];
  5 -> 6 [label = "c"];
  4 -> 4 [label = "a,b"];
  5 -> 5 [label = "a,b"];
  6 -> 6 [label = "a,b"];
}
```
